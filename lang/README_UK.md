### Команди Windows як прості плитки.
Обери тему, натисни плитку, і CMD HELP запустить команду та покаже результат. Нічого не треба вводити чи запам'ятовувати.

## Що вміє

| Функція | Що це означає |
|---|---|
| **51 плитка з командами** | Файли й папки, Диски, Система, Мережа, Інше. Один клік замість запам'ятовування команд. |
| **Каталог A–Z** | Близько 100 команд Windows, кожна з коротким описом. |
| **Власна команда** | Введи будь-яку команду сам, коли потрібно. |
| **Результат наживо** | Відповідь з'являється під час роботи команди. **STOP** її скасовує. |
| **Питає перед будь-чим ризикованим** | Видалення, закриття програми, вимкнення: ти бачиш повну команду й натискаєш **YES** або **NO**. |
| **Адміністратор одним кліком** | Плитки, яким це потрібно, позначені **admin**. |
| **Твій стиль** | 32 мови та 21 кольорова тема. |
| **Приватно** | Без реклами, без стеження, без облікового запису. |

## 📖 Як користуватися, крок за кроком

🟥 Червона рамка показує, **куди натиснути**. 🔴 Цифри **1**, **2** показують, **що натиснути спочатку**.

### 📥 Крок 1. Завантаж

Натисни зелену кнопку **Download** угорі цієї сторінки. Браузер завантажить один файл: **CMD-HELP.exe**.

### 📂 Крок 2. Відкрий завантажений файл

- Натисни на завантажений файл у **правому верхньому куті** браузера,
- або відкрий папку **Завантаження** і двічі натисни **CMD-HELP.exe**.

> 💡 **Порада:** перетягни файл із *Завантажень* на **Робочий стіл**. Наступного разу знайдеш його одразу.

### 🛡️ Крок 3. Синє вікно? Усе гаразд

Першого разу Windows може показати синє вікно: *«Windows захистила ваш ПК»*.
Для маленьких безкоштовних програм це нормально.

1. Натисни **Докладніше**.
2. Натисни **Усе одно запустити**.

<img src="../docs/images/smartscreen_en.png" alt="Синє вікно Windows" width="640">

Це вікно з'являється **лише один раз**. ✅ Програма працює!

## 🖱️ Користування програмою

### 🗂️ Крок 4. Обери тему вгорі

Команди поділено на 5 тем: **Files & folders**, **Disks**, **System**, **Network** і **Other**.
Натисни тему, і її плитки з'являться нижче.

<img src="../docs/steps/s1_categories_en.png" alt="Теми" width="760">

### 🖱️ Крок 5. Натисни плитку

Одна плитка — це одна річ, яку вміє твій комп'ютер. Під назвою є **короткий, простий опис**.
Наприклад: тема **Network** (1), потім плитка **Ping** (2). Ping перевіряє, чи працює інтернет.

<img src="../docs/steps/s2_tile_en.png" alt="Плитка Ping" width="760">

> 💡 Плиток більше, ніж видно. Прокрути вниз коліщатком миші.

### ⌨️ Крок 6. Введи потрібне й натисни RUN

Деякі плитки про щось питають, наприклад адресу сайту чи папку.
У полі вже є **готовий приклад**, тож можна одразу натискати.

1. Поле для введення (для папок є ще кнопка 📁, щоб вибрати мишею).
2. Натисни **▶ RUN**.

<img src="../docs/steps/s3_dialog_en.png" alt="Вікно з полем" width="760">

### 📺 Крок 7. Прочитай результат унизу

Результат з'являється в **чорній області внизу** (консолі).

1. Ось результат.
2. Задовго? Натисни **STOP**.

<img src="../docs/steps/s4_console_en.png" alt="Консоль із результатом" width="760">

> 🧹 **CLEAR CONSOLE** очищає чорну область.

### ⚠️ Крок 8. Плитки з ⚠ питають, перш ніж щось зробити

Плитки з трикутником **⚠** можуть щось змінити на комп'ютері (наприклад, закрити програму чи вимкнути комп'ютер).
Тому програма **завжди спершу питає**:

1. **YES** = зробити.
2. **NO** = нічого не робити.

<img src="../docs/steps/s5_confirm_en.png" alt="Питання YES чи NO" width="760">

> 🛡️ Нічого не станеться, поки не натиснеш **YES**. Не бійся натискати.

### 📚 Крок 9. Хочеш більше? Тема «Other»

1. **All commands A-Z**: повний список команд Windows. Біля кожної написано, що вона робить.
2. **Custom command**: введи будь-яку команду сам (для тих, хто знає консоль).

<img src="../docs/steps/s8_other_en.png" alt="Тема Other" width="760">

### ✅ Крок 10. Готово

Закрий програму звичайним **X** у куті. Вона запам'ятає твою мову й кольори.

## ✨ Додатково

### 🌍 Мова і 🎨 кольори

Угорі праворуч є дві пари стрілок **‹ ›**:

1. **Мова:** 32 мови. Натискай стрілки, доки не побачиш свою.
2. **Кольори (скін):** 21 вигляд. Натискай, доки не сподобається.

<img src="../docs/steps/s7_look_en.png" alt="Мова і кольори" width="760">

### 🔑 «Відмовлено в доступі»

Деякі речі може робити лише **адміністратор** комп'ютера. Такі плитки позначені **admin**.

1. Натисни **RUN AS ADMINISTRATOR** угорі.
2. Windows спитає, чи дозволити. Натисни **Так**.

<img src="../docs/steps/s6_admin_en.png" alt="Запуск від імені адміністратора" width="760">

Програма перезапуститься, уже з потрібними правами. Угорі побачиш **administrator mode**.

### ⓘ Про програму

Кругла кнопка **ⓘ** праворуч унизу показує автора програми та її ліцензію.

<img src="../docs/steps/s9_info_en.png" alt="Кнопка інформації" width="760">

## 🆘 Щось не працює?

| Що я бачу | Що робити |
|---|---|
| Синє вікно *«Windows захистила ваш ПК»* | **Докладніше** → **Усе одно запустити**. Див. Крок 3 вище. |
| Браузер пише, що файл *«нечасто завантажують»* | Натисни **⋯** біля файлу → **Зберегти** → **Показати більше** → **Усе одно зберегти**. |
| Антивірус попереджає | Це часто трапляється з маленькими програмами без платного підпису. Програма запускає лише ті команди Windows, які ти натискаєш. |
| **«Відмовлено в доступі»** | Натисни **RUN AS ADMINISTRATOR**. Див. «Відмовлено в доступі» вище. |
| Довго запускається | Спочатку кілька секунд розпаковується сама. Це нормально. |
| Хочу скинути налаштування | Закрий програму. Введи `%APPDATA%` в адресний рядок папки та видали папку **CMD HELP**. |

Досі не виходить? Напиши на GitHub: [github.com/MRGREGOR85](https://github.com/MRGREGOR85)

## Чи це безпечно?

CMD HELP запускає лише звичайні команди Windows. Усе, що видаляє, закриває чи вимикає, спершу показує повну команду й чекає на твоє **YES**. Нічого не працює у фоні.
