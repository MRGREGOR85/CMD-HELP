### Windows-kommandon som enkla rutor.
Välj ett ämne, klicka på en ruta, så kör CMD HELP kommandot och visar resultatet. Inget att skriva, inget att komma ihåg.

## Vad det gör

| Funktion | Vad det betyder |
|---|---|
| **51 kommandorutor** | Filer och mappar, Diskar, System, Nätverk, Övrigt. Ett klick i stället för att minnas kommandon. |
| **Katalog A–Ö** | Runt 100 Windows-kommandon, alla med en kort beskrivning. |
| **Eget kommando** | Skriv själv valfritt kommando när du behöver. |
| **Resultat direkt** | Svaret visas medan kommandot körs. **STOP** avbryter det. |
| **Frågar före allt riskabelt** | Radera, stänga ett program, stänga av: du ser hela kommandot och klickar **YES** eller **NO**. |
| **Administratör med ett klick** | Rutor som behöver det är märkta **admin**. |
| **Din stil** | 32 språk och 21 färgteman. |
| **Privat** | Ingen reklam, ingen spårning, inget konto. |

## 📖 Så använder du det, steg för steg

🟥 En röd ram visar **var du klickar**. 🔴 Siffrorna **1**, **2** visar **vad du klickar på först**.

### 📥 Steg 1. Ladda ner

Klicka på den gröna knappen **Download** högst upp på sidan. Webbläsaren laddar ner en fil: **CMD-HELP.exe**.

### 📂 Steg 2. Öppna den nedladdade filen

- Klicka på den nedladdade filen i webbläsarens **övre högra hörn**,
- eller öppna mappen **Hämtade filer** och dubbelklicka på **CMD-HELP.exe**.

> 💡 **Tips:** dra filen från *Hämtade filer* till **Skrivbordet**. Nästa gång hittar du den direkt.

### 🛡️ Steg 3. Ett blått fönster? Det är lugnt

Första gången kan Windows visa ett blått fönster: *”Datorn skyddades av Windows”*.
Det är normalt för små gratisprogram.

1. Klicka på **Mer information**.
2. Klicka på **Kör ändå**.

<img src="../docs/images/smartscreen_en.png" alt="Blått Windows-fönster" width="640">

Det här fönstret visas **bara en gång**. ✅ Programmet körs!

## 🖱️ Använda programmet

### 🗂️ Steg 4. Välj ett ämne högst upp

Kommandona är uppdelade i 5 ämnen: **Files & folders**, **Disks**, **System**, **Network** och **Other**.
Klicka på ett ämne så visas dess rutor nedanför.

<img src="../docs/steps/s1_categories_en.png" alt="Ämnen" width="760">

### 🖱️ Steg 5. Klicka på en ruta

En ruta är en sak din dator kan göra. Under namnet finns en **kort, enkel beskrivning**.
Till exempel: ämnet **Network** (1), sedan rutan **Ping** (2). Ping kontrollerar om internet fungerar.

<img src="../docs/steps/s2_tile_en.png" alt="Rutan Ping" width="760">

> 💡 Det finns fler rutor än du ser. Skrolla nedåt med mushjulet.

### ⌨️ Steg 6. Skriv det som behövs och klicka på RUN

Vissa rutor frågar efter något, till exempel en webbadress eller en mapp.
Fältet innehåller redan ett **färdigt exempel**, så du kan klicka direkt.

1. Fältet att skriva i (för mappar finns även en 📁-knapp för att välja med musen).
2. Klicka på **▶ RUN**.

<img src="../docs/steps/s3_dialog_en.png" alt="Fönster med ett fält" width="760">

### 📺 Steg 7. Läs resultatet längst ner

Resultatet visas i det **svarta fältet längst ner** (konsolen).

1. Här är resultatet.
2. Tar det för lång tid? Klicka på **STOP**.

<img src="../docs/steps/s4_console_en.png" alt="Konsol med resultatet" width="760">

> 🧹 **CLEAR CONSOLE** tömmer det svarta fältet.

### ⚠️ Steg 8. Rutor med ⚠ frågar innan de gör något

Rutor med triangeln **⚠** kan ändra något på datorn (till exempel stänga ett program eller stänga av datorn).
Därför **frågar programmet alltid först**:

1. **YES** = gör det.
2. **NO** = gör ingenting.

<img src="../docs/steps/s5_confirm_en.png" alt="Frågan YES eller NO" width="760">

> 🛡️ Inget händer förrän du klickar på **YES**. Var inte rädd att klicka runt.

### 📚 Steg 9. Vill du ha mer? Ämnet ”Other”

1. **All commands A-Z**: hela listan över Windows-kommandon. Varje kommando säger vad det gör.
2. **Custom command**: skriv själv valfritt kommando (för dig som kan konsolen).

<img src="../docs/steps/s8_other_en.png" alt="Ämnet Other" width="760">

### ✅ Steg 10. Klart

Stäng programmet med det vanliga **X** i hörnet. Det kommer ihåg ditt språk och dina färger.

## ✨ Extra

### 🌍 Språk och 🎨 färger

Uppe till höger finns två par pilar **‹ ›**:

1. **Språk:** 32 språk. Klicka på pilarna tills du ser ditt.
2. **Färger (skal):** 21 utseenden. Klicka tills du gillar det.

<img src="../docs/steps/s7_look_en.png" alt="Språk och färger" width="760">

### 🔑 ”Åtkomst nekad”

Vissa saker får bara datorns **administratör** göra. De rutorna är märkta **admin**.

1. Klicka på **RUN AS ADMINISTRATOR** högst upp.
2. Windows frågar om det ska tillåtas. Klicka på **Ja**.

<img src="../docs/steps/s6_admin_en.png" alt="Kör som administratör" width="760">

Programmet startar om, nu med de rättigheter som behövs. Högst upp ser du **administrator mode**.

### ⓘ Om programmet

Den runda knappen **ⓘ** nere till höger visar vem som gjort programmet och dess licens.

<img src="../docs/steps/s9_info_en.png" alt="Infoknapp" width="760">

## 🆘 Fungerar något inte?

| Vad jag ser | Vad jag gör |
|---|---|
| Blått fönster *”Datorn skyddades av Windows”* | **Mer information** → **Kör ändå**. Se Steg 3 ovan. |
| Webbläsaren säger att filen *”inte laddas ner så ofta”* | Klicka på **⋯** bredvid filen → **Behåll** → **Visa mer** → **Behåll ändå**. |
| Mitt antivirus varnar | Det är vanligt för små program utan betald signatur. Programmet kör bara de Windows-kommandon du klickar på. |
| **”Åtkomst nekad”** | Klicka på **RUN AS ADMINISTRATOR**. Se ”Åtkomst nekad” ovan. |
| Det tar en stund att starta | Det packar först upp sig själv i några sekunder. Det är normalt. |
| Jag vill ha inställningarna som nya | Stäng programmet. Skriv `%APPDATA%` i mappens adressfält och ta bort mappen **CMD HELP**. |

Fortfarande fast? Skriv på GitHub: [github.com/MRGREGOR85](https://github.com/MRGREGOR85)

## Är det säkert?

CMD HELP kör bara vanliga Windows-kommandon. Allt som raderar, stänger eller stänger av visar först hela kommandot och väntar på ditt **YES**. Inget körs i bakgrunden.
