### Perintah Windows sebagai ubin sederhana.
Pilih topik, klik sebuah ubin, lalu CMD HELP menjalankan perintah dan menampilkan hasilnya. Tidak perlu mengetik, tidak perlu menghafal.

## Apa yang bisa dilakukan

| Fitur | Artinya |
|---|---|
| **51 ubin perintah** | File dan folder, Disk, Sistem, Jaringan, Lainnya. Sekali klik, tanpa menghafal perintah. |

## 📖 Cara pakai, langkah demi langkah

🟥 Bingkai merah menunjukkan **tempat untuk diklik**. 🔴 Angka **1**, **2** menunjukkan **apa yang diklik lebih dulu**.

### 📥 Langkah 1. Unduh

Klik tombol hijau **Download** di bagian atas halaman ini. Browser mengunduh satu file: **CMD-HELP.exe**.

### 📂 Langkah 2. Buka file yang diunduh

- Klik file yang diunduh di **pojok kanan atas** browser,
- atau buka folder **Downloads** dan klik dua kali **CMD-HELP.exe**.

> 💡 **Tips:** seret file dari *Downloads* ke **Desktop**. Lain kali kamu langsung menemukannya.

### 🛡️ Langkah 3. Jendela biru? Tidak apa-apa

Pertama kali, Windows mungkin menampilkan jendela biru: *“Windows melindungi PC Anda”*.
Ini normal untuk program kecil yang gratis.

1. Klik **Info selengkapnya**.
2. Klik **Tetap jalankan**.

<img src="../docs/images/smartscreen_en.png" alt="Jendela biru Windows" width="640">

Jendela ini muncul **hanya sekali**. ✅ Program berjalan!

## 🖱️ Menggunakan program

### 🗂️ Langkah 4. Pilih topik di atas

Perintah dibagi menjadi 5 topik: **Files & folders**, **Disks**, **System**, **Network**, dan **Other**.
Klik topik dan ubinnya muncul di bawah.

<img src="../docs/steps/s1_categories_en.png" alt="Topik" width="760">

### 🖱️ Langkah 5. Klik sebuah ubin

Satu ubin adalah satu hal yang bisa dilakukan komputermu. Di bawah namanya ada **deskripsi singkat dan sederhana**.
Misalnya: topik **Network** (1), lalu ubin **Ping** (2). Ping memeriksa apakah internet berfungsi.

<img src="../docs/steps/s2_tile_en.png" alt="Ubin Ping" width="760">

> 💡 Ubinnya lebih banyak dari yang terlihat. Gulir ke bawah dengan roda mouse.

### ⌨️ Langkah 6. Ketik yang diperlukan lalu klik RUN

Beberapa ubin meminta sesuatu, misalnya alamat situs atau folder.
Kolomnya sudah berisi **contoh siap pakai**, jadi kamu bisa langsung klik.

1. Kolom untuk mengetik (untuk folder ada juga tombol 📁 untuk memilih dengan mouse).
2. Klik **▶ RUN**.

<img src="../docs/steps/s3_dialog_en.png" alt="Jendela dengan kolom" width="760">

### 📺 Langkah 7. Baca hasilnya di bawah

Hasilnya muncul di **area hitam di bawah** (konsol).

1. Ini hasilnya.
2. Terlalu lama? Klik **STOP**.

<img src="../docs/steps/s4_console_en.png" alt="Konsol dengan hasil" width="760">

> 🧹 **CLEAR CONSOLE** mengosongkan area hitam.

### ⚠️ Langkah 8. Ubin bertanda ⚠ bertanya sebelum melakukan apa pun

Ubin dengan segitiga **⚠** bisa mengubah sesuatu di komputermu (misalnya menutup program atau mematikan komputer).
Karena itu program **selalu bertanya dulu**:

1. **YES** = lakukan.
2. **NO** = jangan lakukan apa pun.

<img src="../docs/steps/s5_confirm_en.png" alt="Pertanyaan YES atau NO" width="760">

> 🛡️ Tidak ada yang terjadi sampai kamu klik **YES**. Jangan takut mencoba.

### 📚 Langkah 9. Mau lebih? Topik “Other”

1. **All commands A-Z**: daftar lengkap perintah Windows. Masing-masing menjelaskan fungsinya.
2. **Custom command**: ketik sendiri perintah apa pun (untuk yang paham konsol).

<img src="../docs/steps/s8_other_en.png" alt="Topik Other" width="760">

### ✅ Langkah 10. Selesai

Tutup program dengan **X** biasa di pojok. Program mengingat bahasa dan warnamu.

## ✨ Tambahan

### 🌍 Bahasa dan 🎨 warna

Di kanan atas ada dua pasang panah **‹ ›**:

1. **Bahasa:** 32 bahasa. Klik panah sampai bahasamu muncul.
2. **Warna (skin):** 21 tampilan. Klik sampai kamu suka.

<img src="../docs/steps/s7_look_en.png" alt="Bahasa dan warna" width="760">

### 🔑 “Akses ditolak”

Beberapa hal hanya boleh dilakukan **administrator** komputer. Ubin seperti itu ditandai **admin**.

1. Klik **RUN AS ADMINISTRATOR** di atas.
2. Windows menanyakan apakah diizinkan. Klik **Ya**.

<img src="../docs/steps/s6_admin_en.png" alt="Jalankan sebagai administrator" width="760">

Program dimulai ulang, kini dengan hak yang dibutuhkan. Di atas kamu akan melihat **administrator mode**.

### ⓘ Tentang program

Tombol bulat **ⓘ** di kanan bawah menunjukkan siapa pembuat program dan lisensinya.

<img src="../docs/steps/s9_info_en.png" alt="Tombol info" width="760">

## 🆘 Ada yang tidak berfungsi?

| Yang saya lihat | Yang harus dilakukan |
|---|---|
| Jendela biru *“Windows melindungi PC Anda”* | **Info selengkapnya** → **Tetap jalankan**. Lihat Langkah 3 di atas. |
| Browser bilang file ini *“jarang diunduh”* | Klik **⋯** di samping file → **Simpan** → **Tampilkan lainnya** → **Tetap simpan**. |
| Antivirus memberi peringatan | Ini umum untuk program kecil tanpa tanda tangan berbayar. Program hanya menjalankan perintah Windows yang kamu klik. |
| **“Akses ditolak”** | Klik **RUN AS ADMINISTRATOR**. Lihat “Akses ditolak” di atas. |
| Lama saat dibuka | Program mengekstrak dirinya dulu selama beberapa detik. Itu normal. |
| Saya ingin pengaturan kembali seperti baru | Tutup program. Ketik `%APPDATA%` di bilah alamat folder lalu hapus folder **CMD HELP**. |

Masih buntu? Tulis di GitHub: [github.com/MRGREGOR85](https://github.com/MRGREGOR85)

## Apakah aman?

CMD HELP hanya menjalankan perintah Windows biasa. Apa pun yang menghapus, menutup, atau mematikan selalu menampilkan perintah lengkapnya dulu dan menunggu **YES** darimu. Tidak ada yang berjalan di latar belakang.
