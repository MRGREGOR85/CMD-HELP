### Команды Windows в виде простых плиток.
Выбери тему, нажми плитку, и CMD HELP выполнит команду и покажет результат. Ничего не нужно вводить и запоминать.

## Что умеет

| Функция | Что это значит |
|---|---|
| **51 плитка с командами** | Файлы и папки, Диски, Система, Сеть, Другое. Один щелчок вместо запоминания команд. |
| **Каталог A–Z** | Около 100 команд Windows, у каждой короткое описание. |
| **Своя команда** | Введи любую команду сам, когда нужно. |
| **Результат вживую** | Ответ появляется во время выполнения команды. **STOP** её отменяет. |
| **Спрашивает перед всем рискованным** | Удаление, закрытие программы, выключение: ты видишь полную команду и нажимаешь **YES** или **NO**. |
| **Администратор одним щелчком** | Плитки, которым это нужно, помечены **admin**. |
| **Твой стиль** | 32 языка и 21 цветовая тема. |
| **Приватно** | Без рекламы, без слежки, без аккаунта. |

## 📖 Как пользоваться, шаг за шагом

🟥 Красная рамка показывает, **куда нажать**. 🔴 Цифры **1**, **2** показывают, **что нажать сначала**.

### 📥 Шаг 1. Скачай

Нажми зелёную кнопку **Download** вверху этой страницы. Браузер скачает один файл: **CMD-HELP.exe**.

### 📂 Шаг 2. Открой скачанный файл

- Нажми на скачанный файл в **правом верхнем углу** браузера,
- или открой папку **Загрузки** и дважды щёлкни **CMD-HELP.exe**.

> 💡 **Совет:** перетащи файл из *Загрузок* на **Рабочий стол**. В следующий раз найдёшь его сразу.

### 🛡️ Шаг 3. Синее окно? Всё в порядке

В первый раз Windows может показать синее окно: *«Система Windows защитила ваш компьютер»*.
Для небольших бесплатных программ это нормально.

1. Нажми **Подробнее**.
2. Нажми **Выполнить в любом случае**.

<img src="../docs/images/smartscreen_en.png" alt="Синее окно Windows" width="640">

Это окно появляется **только один раз**. ✅ Программа работает!

## 🖱️ Работа с программой

### 🗂️ Шаг 4. Выбери тему вверху

Команды разделены на 5 тем: **Files & folders**, **Disks**, **System**, **Network** и **Other**.
Нажми тему, и ниже появятся её плитки.

<img src="../docs/steps/s1_categories_en.png" alt="Темы" width="760">

### 🖱️ Шаг 5. Нажми плитку

Одна плитка — это одно действие, которое умеет твой компьютер. Под названием есть **короткое простое описание**.
Например: тема **Network** (1), затем плитка **Ping** (2). Ping проверяет, работает ли интернет.

<img src="../docs/steps/s2_tile_en.png" alt="Плитка Ping" width="760">

> 💡 Плиток больше, чем видно. Прокрути вниз колёсиком мыши.

### ⌨️ Шаг 6. Введи нужное и нажми RUN

Некоторые плитки что-то спрашивают, например адрес сайта или папку.
В поле уже есть **готовый пример**, так что можно сразу нажимать.

1. Поле для ввода (для папок есть ещё кнопка 📁, чтобы выбрать мышью).
2. Нажми **▶ RUN**.

<img src="../docs/steps/s3_dialog_en.png" alt="Окно с полем" width="760">

### 📺 Шаг 7. Прочитай результат внизу

Результат появляется в **чёрной области внизу** (консоли).

1. Вот результат.
2. Слишком долго? Нажми **STOP**.

<img src="../docs/steps/s4_console_en.png" alt="Консоль с результатом" width="760">

> 🧹 **CLEAR CONSOLE** очищает чёрную область.

### ⚠️ Шаг 8. Плитки с ⚠ спрашивают, прежде чем что-то сделать

Плитки с треугольником **⚠** могут что-то изменить на компьютере (например, закрыть программу или выключить компьютер).
Поэтому программа **всегда сначала спрашивает**:

1. **YES** = выполнить.
2. **NO** = ничего не делать.

<img src="../docs/steps/s5_confirm_en.png" alt="Вопрос YES или NO" width="760">

> 🛡️ Ничего не произойдёт, пока не нажмёшь **YES**. Не бойся нажимать.

### 📚 Шаг 9. Хочешь больше? Тема «Other»

1. **All commands A-Z**: полный список команд Windows. У каждой написано, что она делает.
2. **Custom command**: введи любую команду сам (для тех, кто знает консоль).

<img src="../docs/steps/s8_other_en.png" alt="Тема Other" width="760">

### ✅ Шаг 10. Готово

Закрой программу обычным **X** в углу. Она запомнит твой язык и цвета.

## ✨ Дополнительно

### 🌍 Язык и 🎨 цвета

Вверху справа есть две пары стрелок **‹ ›**:

1. **Язык:** 32 языка. Нажимай стрелки, пока не увидишь свой.
2. **Цвета (скин):** 21 вариант. Нажимай, пока не понравится.

<img src="../docs/steps/s7_look_en.png" alt="Язык и цвета" width="760">

### 🔑 «Отказано в доступе»

Некоторые вещи может делать только **администратор** компьютера. Такие плитки помечены **admin**.

1. Нажми **RUN AS ADMINISTRATOR** вверху.
2. Windows спросит, разрешить ли. Нажми **Да**.

<img src="../docs/steps/s6_admin_en.png" alt="Запуск от имени администратора" width="760">

Программа перезапустится, уже с нужными правами. Вверху увидишь **administrator mode**.

### ⓘ О программе

Круглая кнопка **ⓘ** справа внизу показывает автора программы и её лицензию.

<img src="../docs/steps/s9_info_en.png" alt="Кнопка информации" width="760">

## 🆘 Что-то не работает?

| Что я вижу | Что делать |
|---|---|
| Синее окно *«Система Windows защитила ваш компьютер»* | **Подробнее** → **Выполнить в любом случае**. См. Шаг 3 выше. |
| Браузер пишет, что файл *«скачивают нечасто»* | Нажми **⋯** рядом с файлом → **Сохранить** → **Показать больше** → **Всё равно сохранить**. |
| Антивирус предупреждает | Это обычное дело для небольших программ без платной подписи. Программа выполняет только те команды Windows, которые ты нажимаешь. |
| **«Отказано в доступе»** | Нажми **RUN AS ADMINISTRATOR**. См. «Отказано в доступе» выше. |
| Долго запускается | Сначала несколько секунд распаковывается сама. Это нормально. |
| Хочу сбросить настройки | Закрой программу. Введи `%APPDATA%` в адресную строку папки и удали папку **CMD HELP**. |

Всё ещё не получается? Напиши на GitHub: [github.com/MRGREGOR85](https://github.com/MRGREGOR85)

## Это безопасно?

CMD HELP выполняет только обычные команды Windows. Всё, что удаляет, закрывает или выключает, сначала показывает полную команду и ждёт твоего **YES**. Ничего не работает в фоне.
